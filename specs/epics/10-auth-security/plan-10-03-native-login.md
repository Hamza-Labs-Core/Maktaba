# Plan 10.3 — Native login (JWT access + opaque refresh) — implementation

> Implementation plan for [story-10-03-native-login.md](story-10-03-native-login.md).
> Self-contained: a developer should be able to ship the story from this
> document alone. Depends on `password.Verify` from
> [Plan 10.1](plan-10-01-user-store.md). The signing keys + JWKS surface
> ship in [Story 10.6](story-10-06-rs256-keys-jwks.md) — this plan
> consumes the active-key handle from the keystore but does not
> publish JWKS or rotate keys. Refresh rotation is
> [Plan 10.4](plan-10-04-token-refresh.md) (it shares the
> `refresh_tokens` table and the same `IssuePair` primitive). Streaming
> verification is [Story 10.7](story-10-07-streaming-jwt-verify.md).

## 0. Decisions and departures from `architecture.md` and the story

| #  | Decision | Source | Rationale |
|----|----------|--------|-----------|
| D1 | **Algorithm: RS256** with key resolution by `kid`. We use `github.com/golang-jwt/jwt/v5` for both sign and parse. | arch §9.8 ("short-lived bearer JWT (RS256, 15 min)"); arch §11.2 (`jwt_private_key_env`); story AC-2 ("RS256 signed"). | RS256 lets the Streaming Service verify offline against the public-only JWKS (story 10.7) without sharing a secret. ECDSA would also work but RSA tooling is universally available and the JWKS payload sizes don't matter at our scale. The `golang-jwt/jwt/v5` library is the de-facto Go choice and supports `jwk.Keyfunc`-style resolution by `kid`. |
| D2 | **`jti` is a UUID v7** generated by `github.com/google/uuid` (`uuid.NewV7`). NOT v4. | story AC-2 (`jti=<uuid v7>`). | UUID v7 is time-prefixed, so audit-log queries like "tokens issued in the last hour" are an index range scan instead of a full scan on `jti`. The 48-bit timestamp prefix also makes JTIs naturally unique across replicas without coordination, and Story 10.16's audit table can sort by `jti` and get chronological order for free. v4 would force us to also store `iat` everywhere we want chronology. |
| D3 | **`lib[]` is resolved by a `LibraryACLResolver`** at issue time (and re-resolved on refresh — see Plan 10.4 D2). Admins (`is_admin = true`) get every library id; viewers get the union of `library_acl(user_id)`. The resolver is the SINGLE source of truth — no other code path computes the claim. | story AC-2 ("resolved from `library_acl` table (admins get all libraries)"); Epic 8 Story 8.1 AC-1 (Streaming uses `lib`). | Centralising the lookup in one resolver lets Plan 10.4 reuse it on rotation, lets Story 10.13's permission middleware reuse it for cookie-flow authorization, and lets Story 10.7's tests share a fixture. The "admins get all" rule is non-trivial and we want exactly one place that knows it. The resolver returns `[]string` (UUID strings, in the JSON shape Streaming expects). |
| D4 | **Refresh token: 32 random bytes, base64url-encoded plaintext to the client; argon2id-hashed at rest** with the same `password.Params` we use for user passwords. | story AC-4 ("32-byte url-safe random string; only its argon2id hash is persisted"). | Argon2id (not SHA-256) for refresh tokens is the story's call. The reasoning: even though refresh tokens are 256 bits of entropy (so a fast hash like SHA-256 would also be safe against guessing), argon2id costs `O(memory × time)` per verify — meaning a stolen DB still can't be ground through GPUs. The cost on the verify path is ~30 ms once per refresh request (≤ 1 every 14 minutes per device); negligible. |
| D5 | **Access TTL = `auth.access_ttl_sec` (default 900s = 15 min). Refresh TTL = `auth.refresh_ttl_sec` (default 2 592 000s = 30 d).** Both come from `api.toml`. | arch §11.2; story EC. | These are the canonical values. We expose them as config because lab/staging environments want shorter TTLs to test rotation more aggressively, and the "remember me a long time" scenario for kiosk TVs wants longer refresh. |
| D6 | **Clock-skew leeway = 60 s** on `nbf` and `exp` validation, applied via `jwt.WithLeeway(60 * time.Second)`. NOT applied at issuance (we always sign with the server's `now()`). | story EC ("skewed device clock — Acceptance leeway `clock_skew_leeway_sec` (default 60)"). | A device whose clock is 10 s ahead would otherwise mint requests whose `iat` is in the server's future, which strict parsers reject. Leeway on the verify side lets a slightly-skewed device function. We do NOT widen leeway beyond 60 s — at that point the device's clock is broken and we'd rather force the user to fix it than chain weak guarantees. |
| D7 | **Login flow shares one endpoint with web (Plan 10.2 D1).** `POST /api/auth/login` dispatches on `X-Maktaba-Client: native`. The JWT issuer is invoked for the native branch; there is no dedicated `POST /api/auth/login/native`. | Plan 10.2 D1; story AC-1 ("with `X-Maktaba-Client: native`"). | One endpoint = one URL to allowlist on a corporate firewall, one rate-limit bucket (Story 10.12), one audit row. Branching by header keeps the surface tight. |
| D8 | **Refresh rows live in `refresh_tokens`** with the schema in epic README, plus a UNIQUE index on `hash`. | epic README schema; story AC-4. | The `hash` column needs UNIQUE for two reasons: (1) sanity (collision-free random output), (2) the rotation transaction in Plan 10.4 uses `WHERE hash = $1` to identify the presented token without ambiguity. The id (UUID) is the FK target for the `replaced_by` chain that Plan 10.4 walks for reuse detection. |

If D2 is rejected (UUID v4 jti): audit queries by time become full scans; v7 is free quality.

If D3 is rejected (compute `lib` inline in the handler): Plan 10.4's refresh path duplicates the logic and they drift over the next year of patches; centralising in one resolver type is non-negotiable.

If D4 is rejected (SHA-256 for refresh token at rest): a stolen DB becomes a refresh-token list. Argon2id raises the cost of an offline attack from "free" to "infeasible" with one library call.

```
                            ▼
       ┌────────────────────────────────────────────────────────┐
```

```sql
BEGIN;

CREATE TABLE refresh_tokens (
    id           UUID PRIMARY KEY,                          -- uuid v7
    user_id      UUID NOT NULL REFERENCES users(id) ON DELETE CASCADE,
    hash         TEXT NOT NULL,                             -- argon2id PHC      (D4)
    family_id    UUID NOT NULL,                             -- shared across rotation chain
    issued_at    TIMESTAMPTZ NOT NULL DEFAULT now(),
    expires_at   TIMESTAMPTZ NOT NULL,
    revoked_at   TIMESTAMPTZ,
    replaced_by  UUID REFERENCES refresh_tokens(id),
    client_meta  JSONB NOT NULL DEFAULT '{}'::jsonb,
    CONSTRAINT refresh_tokens_hash_unique UNIQUE (hash)     -- D8
);

-- "All active rows in this family" — the reuse-detection sweep (Plan 10.4).
CREATE INDEX refresh_tokens_user_active
    ON refresh_tokens (user_id, family_id) WHERE revoked_at IS NULL;

-- Reaper sweep for expired-but-not-revoked rows.
CREATE INDEX refresh_tokens_reaper
    ON refresh_tokens (expires_at) WHERE revoked_at IS NULL;

COMMIT;
```

### 2.3 Claims + Issuer (`internal/auth/jwt/`)

```go
// claims.go
package jwt

import (
	"time"

	gjwt "github.com/golang-jwt/jwt/v5"
	"github.com/google/uuid"
)

const (
	Issuer       = "maktaba"
	AudienceAPI  = "api"
	AudStreaming = "streaming"
	AudDirect    = "streaming-direct"
	AudStatic    = "streaming-static"
)

// Claims is the canonical JWT payload (story AC-2 + epic README §"Streaming JWT shape").
type Claims struct {
	gjwt.RegisteredClaims        // iss, aud, sub, iat, exp, jti, nbf
	KeyID    string   `json:"kid"`
	UserID   string   `json:"usr"`
	IsAdmin  bool     `json:"is_admin,omitempty"`
	Lib      []string `json:"lib"`
}

// AsUser flattens claims into the auth-context shape the handlers expect.
type User struct {
	ID         uuid.UUID
	IsAdmin    bool
	Libraries  []string
	JTI        string
	ExpiresAt  time.Time
}

func (c Claims) AsUser() (User, error) {
	uid, err := uuid.Parse(c.UserID)
	if err != nil {
		return User{}, err
	}
	return User{
		ID: uid, IsAdmin: c.IsAdmin, Libraries: c.Lib,
		JTI: c.ID, ExpiresAt: c.ExpiresAt.Time,
	}, nil
}
```

```go
// issuer.go
package jwt

import (
	"crypto/rsa"
	"time"

	gjwt "github.com/golang-jwt/jwt/v5"
	"github.com/google/uuid"
)

type Issuer struct {
	keystore KeyStore
	access   time.Duration // D5
}

func NewIssuer(ks KeyStore, accessTTL time.Duration) *Issuer {
	return &Issuer{keystore: ks, access: accessTTL}
}

// MintAccess issues an RS256 access token with the canonical claims.
// Returns the signed token, its expiry, and the jti (for audit).
func (i *Issuer) MintAccess(userID uuid.UUID, isAdmin bool, lib []string) (string, time.Time, uuid.UUID, error) {
	priv, kid, err := i.keystore.ActiveSigningKey()
	if err != nil {
		return "", time.Time{}, uuid.Nil, err
	}
	now := time.Now().UTC()
	exp := now.Add(i.access)
	jti := uuid.Must(uuid.NewV7()) // D2

	claims := Claims{
		RegisteredClaims: gjwt.RegisteredClaims{
			Issuer:    Issuer,
			Audience:  gjwt.ClaimStrings{AudienceAPI},
			Subject:   userID.String(),
			IssuedAt:  gjwt.NewNumericDate(now),
			NotBefore: gjwt.NewNumericDate(now),
			ExpiresAt: gjwt.NewNumericDate(exp),
			ID:        jti.String(),
		},
		KeyID:   kid,
		UserID:  userID.String(),
		IsAdmin: isAdmin,
		Lib:     lib,
	}

	tok := gjwt.NewWithClaims(gjwt.SigningMethodRS256, claims)
	tok.Header["kid"] = kid                    // D1: parsers resolve by kid
	signed, err := tok.SignedString(priv.(*rsa.PrivateKey))
	return signed, exp, jti, err
}
```

```go
// verifier.go
package jwt

import (
	"errors"
	"strings"
	"time"

	gjwt "github.com/golang-jwt/jwt/v5"
)

type Verifier struct {
	keystore KeyStore
	leeway   time.Duration // D6
	expected string        // expected `aud` value
}

func NewVerifier(ks KeyStore, leeway time.Duration, expectedAud string) *Verifier {
	return &Verifier{keystore: ks, leeway: leeway, expected: expectedAud}
}

var (
	ErrSignature    = errors.New("jwt: bad signature")
	ErrExpired      = errors.New("jwt: expired")
	ErrInvalidToken = errors.New("jwt: invalid")
)

// Parse verifies signature and standard claims and returns the typed Claims.
// Maps library errors to our three failure types so the handler can pick a
// specific `type:` for the problem+json response.
func (v *Verifier) Parse(raw string) (*Claims, error) {
	c := &Claims{}
	tok, err := gjwt.ParseWithClaims(raw, c, func(t *gjwt.Token) (any, error) {
		if t.Method != gjwt.SigningMethodRS256 {
			return nil, ErrSignature
		}
		kid, _ := t.Header["kid"].(string)
		return v.keystore.PublicKey(kid)
	},
		gjwt.WithIssuer(Issuer),
		gjwt.WithAudience(v.expected),
		gjwt.WithLeeway(v.leeway),       // D6
		gjwt.WithValidMethods([]string{"RS256"}),
	)
	if err != nil {
		switch {
		case errors.Is(err, gjwt.ErrTokenExpired):
			return nil, ErrExpired
		case errors.Is(err, gjwt.ErrTokenSignatureInvalid):
			return nil, ErrSignature
		case strings.Contains(err.Error(), "signature"):
			return nil, ErrSignature
		default:
			return nil, ErrInvalidToken
		}
	}
	if !tok.Valid {
		return nil, ErrInvalidToken
	}
	return c, nil
}
```

### 2.4 LibraryACLResolver (`internal/auth/library_acl/resolver.go`) — D3

```go
package library_acl

import (
	"context"

	"github.com/google/uuid"
	"github.com/jackc/pgx/v5/pgxpool"
)

// Resolver is the SINGLE source of truth for the `lib` claim.
// Both login (Plan 10.3) and refresh (Plan 10.4) call Resolve; no other
// path computes the array.
type Resolver struct{ pool *pgxpool.Pool }

func New(pool *pgxpool.Pool) *Resolver { return &Resolver{pool: pool} }

// Resolve returns the library ids the user has read access to.
// Admins receive every library id (D3).
func (r *Resolver) Resolve(ctx context.Context, userID uuid.UUID, isAdmin bool) ([]string, error) {
	var rows pgx.Rows
	var err error
	if isAdmin {
		rows, err = r.pool.Query(ctx,
			`SELECT id FROM libraries ORDER BY id`)
	} else {
		rows, err = r.pool.Query(ctx,
			`SELECT library_id FROM library_acl WHERE user_id = $1 ORDER BY library_id`,
			userID)
	}
	if err != nil {
		return nil, err
	}
	defer rows.Close()
	out := make([]string, 0, 8)
	for rows.Next() {
		var id uuid.UUID
		if err := rows.Scan(&id); err != nil {
			return nil, err
		}
		out = append(out, id.String())
	}
	return out, rows.Err()
}
```

### 2.5 Refresh-token primitives (`internal/auth/native/refresh_token.go`) — D4

```go
package native

import (
	"crypto/rand"
	"encoding/base64"

	"github.com/alexedwards/argon2id"
)

const refreshBytes = 32

func newOpaqueRefresh() (string, string, error) {
	b := make([]byte, refreshBytes)
	if _, err := rand.Read(b); err != nil {
		return "", "", err
	}
	plaintext := base64.RawURLEncoding.EncodeToString(b)
	hash, err := argon2id.CreateHash(plaintext, &argon2id.Params{
		Memory: 65536, Iterations: 2, Parallelism: 1, SaltLength: 16, KeyLength: 32,
	})
	if err != nil {
		return "", "", err
	}
	return plaintext, hash, nil
}

// verifyOpaqueRefresh — used by Plan 10.4's rotation handler.
func verifyOpaqueRefresh(plaintext, phc string) (bool, error) {
	return argon2id.ComparePasswordAndHash(plaintext, phc)
}
```

### 2.7 Native login handler (`internal/auth/native/handler.go`)

```go
package native

import (
	"encoding/json"
	"errors"
	"net/http"
	"time"

	"github.com/google/uuid"
	"github.com/jackc/pgx/v5"

	"maktaba/apps/api/internal/auth/jwt"
	"maktaba/apps/api/internal/auth/library_acl"
	"maktaba/apps/api/internal/auth/password"
	"maktaba/apps/api/internal/auth/user/repo"
	"maktaba/apps/api/internal/problem"
)

type Issuer struct {
	users    *repo.Queries
	tokens   *Queries // package-local sqlc bundle
	jwt      *jwt.Issuer
	resolver *library_acl.Resolver
	cfg      Config
}

type Config struct {
	AccessTTL        time.Duration // 900s
	RefreshTTL       time.Duration // 30d
	MinResponseDelay time.Duration // 500ms (shared with Plan 10.2)
	PasswordParams   password.Params
}

// IssueLogin is the native branch of POST /api/auth/login.
// `start` is passed in so the timing-attack floor (D5/Plan 10.2) is shared.
func (i *Issuer) IssueLogin(w http.ResponseWriter, r *http.Request,
	username, plaintext string, start time.Time) {
	defer i.padTo(start)

	user, err := i.users.GetUserByLowerUsername(r.Context(), username)
	if err != nil && !errors.Is(err, pgx.ErrNoRows) {
		problem.Write(w, 500, "internal", "")
		return
	}
	verifyErr := password.ErrInvalidCredentials
	if err == nil {
		verifyErr = password.Verify(plaintext, user.PwHash)
	}
	if verifyErr != nil {
		problem.Write(w, 401, "invalid-credentials", "username or password is incorrect")
		return
	}

	lib, err := i.resolver.Resolve(r.Context(), user.ID, user.IsAdmin) // D3
	if err != nil {
		problem.Write(w, 500, "internal", "")
		return
	}

	access, accessExp, jti, err := i.jwt.MintAccess(user.ID, user.IsAdmin, lib) // D1, D2
	if err != nil {
		problem.Write(w, 500, "internal", "")
		return
	}

	rt, rtHash, err := newOpaqueRefresh() // D4
	if err != nil {
		problem.Write(w, 500, "internal", "")
		return
	}
	rid := uuid.Must(uuid.NewV7())
	fam := uuid.Must(uuid.NewV7()) // new family on login (Plan 10.4 inherits on rotate)
	rExp := time.Now().Add(i.cfg.RefreshTTL)
	if _, err := i.tokens.InsertRefreshToken(r.Context(), InsertRefreshTokenParams{
		ID: rid, UserID: user.ID, Hash: rtHash, FamilyID: fam,
		ExpiresAt: rExp, ClientMeta: clientMeta(r),
	}); err != nil {
		problem.Write(w, 500, "internal", "")
		return
	}

	writeJSON(w, 200, map[string]any{
		"access_token":       access,
		"access_expires_in":  int(time.Until(accessExp).Seconds()),
		"refresh_token":      rt,
		"refresh_expires_in": int(time.Until(rExp).Seconds()),
		"jti":                jti.String(),
		"user": map[string]any{
			"id": user.ID, "username": user.Username, "is_admin": user.IsAdmin,
		},
	})
}

func (i *Issuer) padTo(start time.Time) {
	left := i.cfg.MinResponseDelay - time.Since(start)
	if left > 0 {
		time.Sleep(left)
	}
}
```

### 2.8 Bearer middleware (`internal/auth/middleware/jwt_auth.go`)

```go
package middleware

import (
	"errors"
	"net/http"
	"strings"

	"maktaba/apps/api/internal/auth/authctx"
	"maktaba/apps/api/internal/auth/jwt"
	"maktaba/apps/api/internal/problem"
)

type BearerAuth struct {
	V *jwt.Verifier
}

func (b *BearerAuth) Middleware(next http.Handler) http.Handler {
	return http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
		raw := strings.TrimPrefix(r.Header.Get("Authorization"), "Bearer ")
		if raw == r.Header.Get("Authorization") || raw == "" {
			next.ServeHTTP(w, r) // hand off to web/cookie middleware lower in the chain
			return
		}
		c, err := b.V.Parse(raw)
		switch {
		case errors.Is(err, jwt.ErrExpired):
			problem.Write(w, 401, "token-expired", "the access token has expired")
			return
		case errors.Is(err, jwt.ErrSignature):
			problem.Write(w, 401, "token-signature", "the access token signature is invalid")
			return
		case err != nil:
			problem.Write(w, 401, "token-invalid", "the access token is invalid")
			return
		}
		u, err := c.AsUser()
		if err != nil {
			problem.Write(w, 401, "token-invalid", "")
			return
		}
		ctx := authctx.WithUser(r.Context(), authctx.User{
			ID: u.ID, IsAdmin: u.IsAdmin, Libraries: u.Libraries, JTI: u.JTI,
		})
		next.ServeHTTP(w, r.WithContext(ctx))
	})
}
```

## 5. Edge cases and how the plan handles each

| #  | Edge case | Handled by |
|----|-----------|------------|
| E1 | **Skewed device clock** — token `iat` is up to 60 s in the server's future. | `WithLeeway(60 * time.Second)` on the verifier (D6). Tested in `TestVerifierLeeway`. |
| E2 | **Native client missing `X-Maktaba-Client: native`**. | Falls into web flow (Plan 10.2 D1); the API sets cookies; the client ignores them. (Plan 10.2's `TestLoginNativeHeaderRoutesToJWTFlow` is the inverse case.) |
| E3 | **User with no library access.** | `Resolver.Resolve` returns `[]string{}`; `Claims.Lib = []`; Streaming Service rejects all signed URLs (Story 8.1). Tested in `TestNativeLoginEmptyLibForViewerWithoutACL`. |
| E4 | **User's library ACL changes after issue.** | Claim is a snapshot; access TTL = 15 min bounds the staleness. Refresh re-snapshots (Plan 10.4 D2). Documented in story EC. |
| E5 | **Tampered JWT.** | `Verifier.Parse` returns `ErrSignature` → 401 `token-signature`. Tested in `TestJWTAuthTampered`. |
| E6 | **Expired JWT.** | `ErrExpired` → 401 `token-expired`. Tested in `TestJWTAuthExpired`. |
| E7 | **Token with unknown `kid`.** | `KeyStore.PublicKey(kid)` returns an error; the verifier's keyfunc surfaces it; classified as `token-invalid`. (Cross-story: tests for kid lookup live in Story 10.6.) |
| E8 | **Token signed by a key that has been retired but whose `kid` is still served by JWKS.** | Story 10.6 keeps retired public keys for `2 × refresh_ttl_sec` so the verifier still accepts them; Plan 10.3 has no special handling. |
| E9 | **Refresh-token collision** (impossible at 256 bits). | `refresh_tokens_hash_unique` causes INSERT to fail with UNIQUE violation; handler returns 500 (operator alert). |
| E10 | **Login race: two simultaneous logins for the same user.** | Each path generates its own UUIDs and tokens; both rows insert successfully (UNIQUE only checks `hash` collision, not user). Both clients are valid; this is by design (multi-device). |
| E11 | **Empty Authorization header**. | Middleware passes through without authenticating; downstream cookie middleware (Plan 10.2) gets a chance. If neither auth is present, the protected handler eventually returns 401. |
| E12 | **Authorization header without "Bearer " prefix**. | Middleware does not match the bearer shape; passes through. |
| E13 | **Native login with a locked user (Story 10.11)**. | The user-store layer (10.11) sets `locked_until > now()` and the password verify path is short-circuited; collapsed into `invalid-credentials`. The 500 ms timing floor still applies (D5). |
| E14 | **Refresh token leaked then used to mint multiple accesses.** | The rotation in Plan 10.4 detects reuse and revokes the family; this plan's responsibility is only ensuring the token is opaque + hashed at rest (D4). |

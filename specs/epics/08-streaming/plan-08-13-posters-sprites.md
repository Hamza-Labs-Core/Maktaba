# Implementation Plan — Story 8.13 Posters, Sprite Sheets, Chapter Thumbs

> Companion to [story-08-13-posters-sprites.md](story-08-13-posters-sprites.md).
> The story states *what* and *why*; this plan states *how*. Architecture
> reference: [§4.9](../../architecture.md#49-thumbnails-and-previews).
> All paths require a `streaming-static` JWT enforced by the middleware
> from [Story 8.1](plan-08-01-server-skeleton.md).

## 0. Scope and placement

| Concern | Decision |
|---|---|
| Package | `streaming/internal/handlers/static/` — three handlers (poster, sprite, thumbs), one shared serve helper. |
| File source | Pre-generated by Pipeline (Epic 4 thumbnail stage) at `cache/posters/{hash[:2]}/{hash}.jpg` etc. We never generate here. |
| Path-cum-sub | The `sub` claim equals `sha256("posters/<hash>.jpg")` (or the analogue for sprites/thumbs). The middleware computes the expected hash from the URL path and compares against `cl.Subject`. |
| Caching | `Cache-Control: private, max-age=2592000, immutable` (story AC-1 — `private`, not `public`, because each user has a unique signed URL). |
| Range support | Reuses `direct.Handler.ServeFile` (Story 8.3) so the sprite WebP and chapter JPGs all get conditional-GET + range out of the box. |
| VTT URL rewrite | The sprite VTT references the WebP by relative URL; the handler rewrites that line at serve time to inherit the request's `?sig=<jwt>` so the player's WebP fetch carries a valid static JWT. |
| Out of scope | Generation (Pipeline). Public sharing (we don't expose a "share thumbnail" feature in v1). |

```go
// streaming/internal/handlers/static/sub.go
package static

import (
    "crypto/sha256"
    "encoding/hex"
    "fmt"
)

// expectedPosterSub returns the canonical `sub` claim value for a poster
// signed URL. Streaming Service and the API's URL-minter both compute
// the same value from the same string.
func expectedPosterSub(hash string) string {
    sum := sha256.Sum256([]byte("posters/" + hash + ".jpg"))
    return hex.EncodeToString(sum[:])
}
func expectedSpriteWebPSub(hash string) string {
    sum := sha256.Sum256([]byte("sprites/" + hash + ".webp"))
    return hex.EncodeToString(sum[:])
}
func expectedSpriteVTTSub(hash string) string {
    sum := sha256.Sum256([]byte("sprites/" + hash + ".vtt"))
    return hex.EncodeToString(sum[:])
}
func expectedThumbSub(hash string, idx int) string {
    s := fmt.Sprintf("thumbs/%s/chapter-%d.jpg", hash, idx)
    sum := sha256.Sum256([]byte(s))
    return hex.EncodeToString(sum[:])
}
```

### 2.4 Sprite VTT rewriter

The Pipeline-generated sprite VTT looks like:

```
WEBVTT

00:00:10.000 --> 00:00:20.000
sprite.webp#xywh=0,0,160,90

00:00:20.000 --> 00:00:30.000
sprite.webp#xywh=160,0,160,90
```

We rewrite the `sprite.webp...` lines to include the same `?sig=<jwt>`
the client used so its inner fetch carries a valid static JWT.

```go
// streaming/internal/handlers/static/sprite_vtt.go
package static

import (
    "bufio"
    "io"
    "regexp"
    "strings"
)

// imageRefLine matches a line of the form `<basename>.webp#xywh=...`
// (no leading whitespace). The rewriter splices `?sig=<jwt>` between
// the basename and the fragment.
var imageRefLine = regexp.MustCompile(`^([^\s/?#]+\.webp)(#xywh=[\d,]+)\s*$`)

func RewriteSpriteVTT(in io.Reader, out io.Writer, sigQuery string) error {
    sc := bufio.NewScanner(in)
    sc.Buffer(make([]byte, 64*1024), 1024*1024)
    for sc.Scan() {
        line := sc.Text()
        if m := imageRefLine.FindStringSubmatch(line); m != nil {
            line = m[1] + "?" + sigQuery + m[2]
        }
        if _, err := io.WriteString(out, line+"\n"); err != nil {
            return err
        }
    }
    return sc.Err()
}
```

### 2.5 Handlers

```go
// streaming/internal/handlers/static/poster.go
package static

import (
    "errors"
    "io/fs"
    "net/http"
    "os"

    "github.com/go-chi/chi/v5"
    "github.com/google/uuid"

    "maktaba/streaming/internal/handlers/direct"
    "maktaba/streaming/internal/httpx"
    "maktaba/streaming/internal/probe"
)

type PosterHandler struct {
    Probe   probe.Lookup
    Direct  *direct.Handler
    CacheRoot string
    Metrics *Metrics
}

func (h *PosterHandler) Serve(w http.ResponseWriter, r *http.Request) {
    vidStr := chi.URLParam(r, "video_id")
    vid, err := uuid.Parse(vidStr)
    if err != nil {
        httpx.Write(w, http.StatusBadRequest, "bad-video-id", "invalid video id", "")
        return
    }
    row, err := h.Probe.LookupVideo(r.Context(), vid)
    if err != nil {
        httpx.Write(w, http.StatusNotFound, "video-not-found", "video not found", "")
        return
    }
    path := posterPath(h.CacheRoot, row.ContentHash)

    stat, err := os.Stat(path)
    if errors.Is(err, fs.ErrNotExist) || (err == nil && stat.Size() == 0) {
        // 0-byte files (interrupted Pipeline write) treated as missing.
        h.Metrics.Served.WithLabelValues("poster", "404").Inc()
        httpx.Write(w, http.StatusNotFound, "poster-not-generated", "poster not yet generated", "")
        return
    } else if err != nil {
        httpx.Write(w, 500, "poster-stat-failed", "", err.Error())
        return
    }

    w.Header().Set("Cache-Control", "private, max-age=2592000, immutable")
    // Static-asset MIME is fixed by handler — there is no DB MIME column.
    // ServeFile uses the explicit contentType argument when set; otherwise
    // it falls back to the file-extension helper.
    h.Direct.ServeFileWithContentType(w, r, path, "image/jpeg", &probe.Row{
        Path: path, ContentHash: row.ContentHash,
    })
    h.Metrics.Served.WithLabelValues("poster", "200").Inc()
}
```

```go
// streaming/internal/handlers/static/sprite.go
package static

func (h *SpriteHandler) Serve(w http.ResponseWriter, r *http.Request) {
    vidStr := chi.URLParam(r, "video_id")
    ext := chi.URLParam(r, "ext") // "webp" | "vtt"
    vid, err := uuid.Parse(vidStr)
    if err != nil {
        httpx.Write(w, http.StatusBadRequest, "bad-video-id", "invalid video id", "")
        return
    }
    row, err := h.Probe.LookupVideo(r.Context(), vid)
    if err != nil {
        httpx.Write(w, http.StatusNotFound, "video-not-found", "video not found", "")
        return
    }

    switch ext {
    case "webp":
        path := spriteWebPPath(h.CacheRoot, row.ContentHash)
        if !fileExistsNonzero(path) {
            httpx.Write(w, http.StatusNotFound, "sprite-not-generated", "", "")
            return
        }
        w.Header().Set("Cache-Control", "private, max-age=2592000, immutable")
        // Sprite MIME is a fixed handler constant — no DB MIME column.
        h.Direct.ServeFileWithContentType(w, r, path, "image/webp", &probe.Row{
            Path: path, ContentHash: row.ContentHash,
        })
    case "vtt":
        path := spriteVTTPath(h.CacheRoot, row.ContentHash)
        f, err := os.Open(path)
        if err != nil {
            httpx.Write(w, http.StatusNotFound, "sprite-vtt-not-generated", "", "")
            return
        }
        defer f.Close()
        w.Header().Set("Content-Type", "text/vtt; charset=utf-8")
        w.Header().Set("Cache-Control", "private, max-age=2592000, immutable")
        // Inherit the request's full query string into rewritten URLs.
        if err := RewriteSpriteVTT(f, w, r.URL.RawQuery); err != nil {
            return
        }
    default:
        httpx.Write(w, http.StatusBadRequest, "bad-ext", "unsupported extension", ext)
    }
}
```

### 2.6 Middleware extension — computed sub

The middleware in Story 8.1 took the sub from a URL parameter. For
static routes the sub is **derived from the URL**, not a parameter. We
add an alternative middleware factory:

```go
// streaming/internal/auth/middleware.go (added)

// SignedURLComputed is like SignedURL but derives the expected sub from
// the URL via subFn, instead of pulling a chi URL parameter.
//
// subFn receives the request after the JWT was successfully extracted
// and parsed; it returns the expected `sub` value or an error which is
// surfaced as 404 / 401 depending on type.
func SignedURLComputed(
    j *Cache, policy AudPolicy,
    subFn func(*http.Request) (string, error),
    leeway time.Duration,
) func(http.Handler) http.Handler {
    return func(next http.Handler) http.Handler {
        return http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
            tok, problem := extractAndVerify(r, j, leeway)
            if problem != "" { httpx.WriteSignedURLError(w, problem); return }
            cl, err := parseStreamingClaims(tok)
            if err != nil { httpx.WriteSignedURLError(w, err.Error()); return }
            if cl.Audience != string(policy) { httpx.WriteSignedURLError(w, "wrong-aud"); return }

            wanted, err := subFn(r)
            if errors.Is(err, errResourceNotFound) {
                httpx.Write(w, http.StatusNotFound, "resource-not-found", "", err.Error())
                return
            }
            if err != nil || cl.Subject != wanted {
                httpx.WriteSignedURLError(w, "wrong-sub")
                return
            }

            ctx := context.WithValue(r.Context(), ctxKeyClaims, cl)
            ctx = context.WithValue(ctx, ctxKeySubject, cl.Subject)
            ctx = context.WithValue(ctx, ctxKeyLibIDs, cl.LibIDs)
            next.ServeHTTP(w, r.WithContext(ctx))
        })
    }
}
```

The router wires this with closures that resolve the expected sub:

```go
// streaming/internal/server/router.go (excerpt)
r.Route("/stream/posters", func(r chi.Router) {
    r.Use(auth.SignedURLComputed(jwks, auth.AudStatic, func(req *http.Request) (string, error) {
        vid, err := uuid.Parse(chi.URLParam(req, "video_id"))
        if err != nil { return "", errInvalidVideoID }
        row, err := probeLookup.LookupVideo(req.Context(), vid)
        if err != nil { return "", errResourceNotFound }
        return static.ExpectedPosterSub(row.ContentHash), nil
    }, leeway))
    r.Use(auth.LibraryGuard(probeLookup))
    r.Get("/{video_id}.jpg", posterHandler.Serve)
})
```

This means the **probe row is already loaded** by the middleware via
the closure; the handler can rely on the same probe cache (Story 8.15)
to be hot.

## 5. Edge cases — handling table

| Case | Behaviour | Where it's pinned |
|---|---|---|
| Poster file is 0 bytes (interrupted Pipeline write) | Treated as missing → 404; the Pipeline retry will regenerate. | `TestPosterHandler_ZeroByteFile_404` |
| WebP not supported by an ancient client | Out of scope; the player falls back to no scrub preview (the `.vtt` returns valid cues but the inline image will fail to load on the client side). We don't transcode WebP → JPEG. | Documented; no test. |
| Stolen poster URL replayed for a different video | sub is `sha256("posters/<hash>.jpg")`; another video has a different content_hash → 401 `wrong-sub`. | `TestStatic_WrongVideoSub_401` |
| Stolen session JWT replayed on poster URL | Aud mismatch → 401 `wrong-aud`. | `TestStatic_WrongAud_401` |
| Range request on a poster | Delegated to `direct.ServeFile`; works (sendfile). | `TestPosterHandler_RangeServed206` |
| ETag conditional GET | 304 returned. AC test. | `TestPosterHandler_IfNoneMatchETag_304` |
| Sprite VTT lines without the expected pattern | Pass through verbatim; the rewriter only touches matching `*.webp#xywh=...` lines. | `TestRewriteSpriteVTT_PreservesNonImageLines` |
| Sprite VTT references an absolute URL | The regex requires no slash/`?` before `.webp` — absolute URLs are not rewritten (and shouldn't appear; Pipeline emits relative paths). | `TestRewriteSpriteVTT_DoesNotDoubleEncode` |
| Cache GC unlinks while serving | Open FD continues serving (POSIX inode survival). | Cross-link to Story 8.14. |
| EvictHashCache during a serving | Same as above. | Cross-link to Story 8.8. |

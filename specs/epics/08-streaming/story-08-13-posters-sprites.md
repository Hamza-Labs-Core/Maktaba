# Story 8.13 — Posters, sprite sheets, chapter thumbs

Static assets generated by the Pipeline and served as plain HTTP per
§4.9. All paths require a `streaming-static` JWT (Story 8.1 AC-5);
posters and sprites are not public.

**AC-1 — Poster.**
- **Given** an authenticated `GET /stream/posters/{video_id}.jpg?sig=<jwt>`,
- **When** the JWT is valid (`aud=streaming-static`,
  `sub=<artifact-hash>`, `lib[]` contains the video's library) and the
  file exists in `cache/posters/{hash[:2]}/{hash}.jpg`,
- **Then** it's served with `Cache-Control: private, max-age=2592000,
  immutable`, `Content-Type: image/jpeg`. Note: `private` (not `public`)
  because each user's signed URL is unique; shared CDN caching would
  break the JWT model.
- **When** missing (Pipeline hasn't run thumbnail stage), returns 404.

**AC-2 — Sprite sheet + VTT.**
- **Given** an authenticated `GET /stream/sprites/{video_id}.webp?sig=<jwt>`
  and `.vtt`,
- **When** both exist and the JWT validates,
- **Then** they're served similarly. The `.vtt` references the sprite
  by relative URL; the player consumes both for scrub previews. The
  relative reference inherits the same `?sig=<jwt>` query parameter
  the client provided (the `.vtt` rewrites embedded URLs at serve time).

**AC-3 — Chapter thumbs.**
- **Given** `GET /stream/thumbs/{video_id}/chapter-{n}.jpg?sig=<jwt>`,
- **When** the JWT validates and the file exists,
- **Then** it's served; missing → 404.

**Test cases:**
- Integration: ETag/`If-None-Match` correctly returns 304 on
  unchanged poster.
- Integration: serving 100 poster requests in parallel uses zero CPU
  (sendfile path).
- Security: a `streaming-static` JWT for video A cannot be used to fetch
  video B's poster (the `sub` claim differs).
- Security: a `streaming` JWT (session audience) sent to a poster URL
  is rejected with `wrong-aud`.

**Edge cases:**
- Poster file is 0 bytes (interrupted Pipeline write) — detected by a
  size check; treated as missing → 404; the Pipeline retry will
  regenerate.
- WebP not supported by an ancient client — out of scope; the player
  falls back to no scrub preview.

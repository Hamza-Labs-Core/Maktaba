# Implementation Plan — Story 20.3 Unit Test Coverage & Conventions

> Companion to [story-20-03-unit-test-coverage.md](story-20-03-unit-test-coverage.md).
> Per-package coverage floors, generated-code excludes, error-path lint,
> mutation testing on critical paths.

## 0. Scope and placement

| Concern | Decision |
|---|---|
| Coverage tools | Go `go test -cover` + `gocover-cobertura`; Python `coverage.py`; TS `vitest --coverage` (v8). |
| Excludes | sqlc/gqlgen/pb/codegen patterns excluded per language. |
| Per-package floors | `tools/coverage/floors.yaml` — single source of truth. |
| Error-path lint | Custom Go AST walker: every public `func ... error` must have at least one test exercising the error return. |
| Mutation testing | Weekly: `go-mutesting` for Go critical paths, `mutmut` for Python. |
| Out of scope | Integration coverage (different goal). |

## 3. Coverage gate

```go
// tools/coverage/enforce.go
func main() {
    floors := loadFloors("tools/coverage/floors.yaml")
    cov := loadCoberturaXML(os.Args[1])     // generated by go test -coverprofile + gocover-cobertura
    var fail bool
    for _, p := range floors.Packages {
        actual := cov.LineRateFor(p.Path)
        if actual*100 < float64(p.Floor) {
            fmt.Fprintf(os.Stderr, "FAIL: %s coverage=%.1f%% floor=%d%%\n", p.Path, actual*100, p.Floor)
            fail = true
        }
    }
    // EC2: print measured file list
    cov.PrintMeasuredFiles(os.Stdout)
    if fail { os.Exit(1) }
}
```

`make coverage:gate` runs in PR CI after `make coverage:collect`.

## 4. Error-path lint

```go
// tools/coverage/error_path_lint.go
//go:build coveragelint

func main() {
    // For every public function returning error, ensure at least one test
    // reaches the err != nil return.
    fset := token.NewFileSet()
    pkgs, _ := packages.Load(&packages.Config{Mode: packages.NeedSyntax|packages.NeedTypes|packages.NeedTypesInfo|packages.NeedDeps, Tests: true}, "./...")
    fns := collectErrorReturning(pkgs)
    tests := collectTestNames(pkgs)
    for _, fn := range fns {
        if !testTouchesErrorReturn(fn, tests) {
            fmt.Printf("WARN: %s has no test exercising error return\n", fn.Pos())
        }
    }
}
```

The check uses static analysis to detect a test calls the function with arguments that drive any error branch. False-positives are silenced via `// nolint:errpath REASON` comment in the test file.

Nightly script:

```bash
#!/usr/bin/env bash
# tools/coverage/mutation/nightly.sh
set -euo pipefail
go install github.com/avito-tech/go-mutesting@latest
report=mutation-$(date +%Y%m%d).json
go-mutesting --config=tools/coverage/mutation/go_mutesting.yaml --json > "$report"
surviving_auth=$(jq '.results | map(select(.path | startswith("api/internal/auth"))) | map(select(.killed == false)) | length' "$report")
surviving_hash=$(jq '.results | map(select(.path | startswith("shared/contenthash"))) | map(select(.killed == false)) | length' "$report")
echo "auth_survivors=$surviving_auth"
echo "hash_survivors=$surviving_hash"
[ "$surviving_auth" -le 5 ] || { echo "auth survivors > 5"; exit 1; }
[ "$surviving_hash" -eq 0 ] || { echo "hash survivors > 0"; exit 1; }
```

## 6. `init()` ban (EC3)

```go
// tools/coverage/lint_no_init.go
//go:build initlint

func main() {
    fset := token.NewFileSet()
    err := filepath.Walk(".", func(path string, info os.FileInfo, _ error) error {
        if info.IsDir() && (info.Name() == "cmd" || info.Name() == "vendor") { return filepath.SkipDir }
        if !strings.HasSuffix(path, ".go") || strings.HasSuffix(path, "_test.go") { return nil }
        f, _ := parser.ParseFile(fset, path, nil, 0)
        for _, d := range f.Decls {
            if fn, ok := d.(*ast.FuncDecl); ok && fn.Name.Name == "init" && fn.Recv == nil {
                fmt.Fprintf(os.Stderr, "init() forbidden outside cmd/: %s\n", fset.Position(fn.Pos()))
                os.Exit(1)
            }
        }
        return nil
    })
    if err != nil { os.Exit(1) }
}
```

Exception: `cmd/*` may use `init()` (tools).

## 7. Test cases

### TC1 — Coverage gate
Drop a test file from `api/internal/domain`; `make coverage:gate` exits non-zero with "domain coverage=X% floor=85%".

### TC2 — Error-path lint
Create a function `func F() error { return errors.New("boom") }` with no test. Run `make lint:errpath`; assert WARN line names the function.

### TC3 — Mutation report
Mutate an `==` to `!=` in `auth/verify.go` (synthetic). Nightly mutation run. Assert the mutant is killed by an existing test (i.e. the test fails). If the mutant survives, the auth survivors counter increments and the gate fires.

### EC1 — Happy-path-only file
File with one test covering the only valid input. Lint flags missing error-path test.

### EC2 — Generated counted
Add `pkg/foo/zz_generated.go`. `make coverage:gate` runs and prints "skipping zz_generated.go (excluded)" and the floor calculation excludes it.

### EC3 — `init()` forbidden
Add `init()` to a non-`cmd` package; lint exits non-zero with file path.

## 8. Edge cases summary

| Case | Source | Handling |
|---|---|---|
| EC1 happy-path-only | story | error-path lint flags. |
| EC2 generated counted | story | `excludes:` per-language; print measured files. |
| EC3 init() ordering | story | initlint forbids outside `cmd/`. |
| Floor regression by package split | impl | Add the new sub-package to floors.yaml in same PR. |
| Test imports tested package indirectly | impl | Coverage tool walks transitive; floors are per-imported-package. |

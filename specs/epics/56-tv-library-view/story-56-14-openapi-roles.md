# Story 56.14 — OpenAPI and role tests for the library routes

> Epic 56 · Phase 1 (last) · Depends on: 56.01, 56.04, 56.05, 56.08, 56.09 · Needed by: —

## Why

`shared/api/openapi.json` describes `/libraries` and `/collections` only, names the collection
items path `/collections/{id}/videos` while the code serves `/items`, and leaves out series,
seasons, playlists, hubs, home, facets and `/me/*`, which every TV and Player reads. The API must
also prove every role rule of this epic with a test (no hidden-UI rules).

## Description

### 1. OpenAPI

Describe, with request and response schemas and error codes:

- the existing routes the apps read: `GET /api/libraries/summary`, `/libraries/{id}/hub`,
  `/libraries/{id}/series`, `/libraries/{id}/collections`, `/libraries/{id}/collections/{kind}/{gid}`,
  `/home`, `/videos` (all its filters, `group`), `/videos/facets`, `/series`, `/series/{id}`,
  `/series/{id}/episodes`, `/me/playlists` and its sub-routes, `/me/watched`, `/me/favorites`,
  `/me/pinned-libraries`;
- this epic's new routes (README §6.3);
- fix `/collections/{id}/videos` → `/collections/{id}/items`.

The Arabic summaries go in `shared/api/openapi.ar.json` (the wiki reads them).

A Go test walks the router and fails on a mounted `/api/` route of these handlers that the
document does not describe, so it cannot fall behind again.

### 2. Role tests

One table-driven test per handler package, run as no one, a viewer of another library, a viewer
of the library, another user, and an admin, for every route of README §6.3:

| Route kind | No session | Viewer, other library | Viewer of the library | Other user's object | Admin |
|---|---|---|---|---|---|
| Reads of a library's data | 401 | 404 | 200 | — | 200 |
| Collection and library writes | 401 | 403 | 403 | — | 200 |
| `/me/play-queues/*`, `/me/playlists/*` | 401 | — | own: 200 | 404 | own: 200 (an admin cannot read another user's queue or playlist) |

## Acceptance criteria

- **Given** the router, **when** the coverage test runs, **then** every route of the listed handlers
  is described, and removing one from the document fails it.
- **Given** each cell of the table, **then** the role test asserts it.
- **Given** the wiki generator, **then** `python3 docs/wiki/db/generate_wiki.py --check` passes with
  the new endpoints and their Arabic summaries.

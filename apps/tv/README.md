# `apps/tv/` — TV apps (Phase 12, Epic 14)

Two native TV shells:

| Subdir | Stack | Story |
|---|---|---|
| [`tvos/`](tvos/) | SwiftUI + AVPlayer + Apollo iOS | [14.1](../../specs/epics/14-tv-apps/story-14-01-tvos.md) |
| [`android/`](android/) | Kotlin + Compose-TV + ExoPlayer + Apollo Kotlin | [14.2](../../specs/epics/14-tv-apps/story-14-02-android-tv.md) |

Phase 12 scaffolds the **package structure, key views, GraphQL client
stubs, and service interfaces**. The native projects are generated by
`xcodebuild`/Gradle and not committed — only the Swift Package /
Gradle module sources live here.

## 10-foot UI (Story 14.3)

Both shells consume `web/design-system/tokens/tv.json` (the TV-specific
token bundle): 32 px focus rings, 96 px safe-area gutters, T1/T2/T3
type scale. See [story-14-03](../../specs/epics/14-tv-apps/story-14-03-10-foot-ui.md).

## Voice search (Story 14.4)

tvOS uses `INSpeakableString` Siri intents; Android TV uses
`SearchOrbView` + the Google Assistant content provider. Both
forward the resolved transcript to `GET /api/search/suggest`.

## Continue Watching / Recommendations (Stories 14.5–14.7)

Both rows are GraphQL queries (`continueWatching`, `recommendations`).
The recs API contract lives at `GET /api/recommendations`
([story 14.7](../../specs/epics/14-tv-apps/story-14-07-recommendations-api.md)).

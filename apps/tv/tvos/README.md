# Maktaba TV (Apple TV)

A SwiftUI app for Apple TV (tvOS 26): a home's libraries on the television, driven with
the Siri remote. It is the **"Maktaba TV"** target of the Apple apps' Xcode project
(`apps/apple/project.yml` → `Maktaba.xcodeproj`) and is built on **MaktabaKit**, the
package the iPhone, iPad and Mac apps share: the API client (`X-Maktaba-Client: native`,
the 15-minute access token and its refresh), the Keychain session per home, the stream
proxy, Bonjour discovery and the "Ink & Brass" colours. The screens are the TV's own.

## Layout

```
tvos/
├── MaktabaTV/
│   ├── MaktabaTVApp.swift        # @main: the session (MaktabaKit), choose a home → sign in → tabs
│   ├── ContentView.swift         # top tab bar: Home / Libraries / Search / Settings
│   ├── Views/
│   │   ├── StartViews.swift      # homes on the network (Bonjour) or by address; sign in by code or password
│   │   ├── HomeView.swift        # the home's rails (continue watching first) over the library scene
│   │   ├── LibraryView.swift     # libraries, a library's videos (paged), the video card
│   │   ├── VideoPage.swift       # a video: Resume from where you stopped, or Play
│   │   ├── PlayerView.swift      # TVPlayback (stream session + StreamProxy + progress) and the system player
│   │   ├── SearchView.swift      # .searchable: the TV keyboard and Siri dictation
│   │   └── SettingsView.swift    # who, which home, theme, sign out
│   ├── Theme/Theme.swift         # palette, fonts, library backdrop, reading panel, gold focus ring
│   ├── Resources/                # layered tvOS icon + Top Shelf, OFL fonts, the library art
│   └── Info.plist                # generated by XcodeGen from project.yml
└── MaktabaTVUITests/             # drives the app with the Siri remote against a real home
```

## How it works

- **Finding the home.** A home announces `_maktaba._tcp` on the LAN (its web port in the
  TXT record); the TV lists them (`HomeBrowser`), else takes a typed address.
- **Signing in.** Typing a password with a remote is slow, so the TV shows a code and a QR
  code of `<home>/pair?code=…`. Someone signed in on a phone or computer approves it and the
  TV is signed in as them, with their own role (`POST /api/pairing/device`, `/approve`,
  `/device/token`; see `api/internal/handlers/discovery/device.go`). A password is the
  other way, and the only one on a home from before codes.
- **Playback.** As in the Player apps: a stream session from the home, read through
  MaktabaKit's `StreamProxy` (the home's web port wants `Authorization: Bearer` on every
  `/stream/` request and AVPlayer cannot renew a token), the position reported every 10 s,
  a transcode awaited until its playlist exists (`waitUntilPlayable`). The system player
  gives the transport bar, scrubbing, audio and subtitle choices.
- **Resume.** A video's page offers "Resume from 12:34" (its `playback_state`), focused first.
- **10-foot UI.** The focus engine with a gold ring and lift on the focused card, big type,
  80 pt gutters for overscan, Amiri and IBM Plex Sans Arabic. Dark by default; Settings can
  follow the system or go light.

## Build and run

```bash
cd apps/apple && xcodegen          # after changing project.yml
make tv-build-ios                  # simulator build (what CI runs on a release tag)
```

Open `apps/apple/Maktaba.xcodeproj`, pick the **Maktaba TV** scheme and an Apple TV
simulator, Run. Signing is automatic (team G58UVTKQPB), as for the other Apple apps.

The UI tests need a home and an account, passed through the environment:

```bash
TEST_RUNNER_MAKTABA_HOME=http://192.168.50.177:8088 TEST_RUNNER_MAKTABA_USER=… TEST_RUNNER_MAKTABA_PASSWORD=… \
  xcodebuild -project apps/apple/Maktaba.xcodeproj -scheme "Maktaba TV" \
  -destination 'platform=tvOS Simulator,name=Apple TV 4K (3rd generation)' test
```

Without `MAKTABA_HOME` they are skipped. The tvOS simulator does not see Bonjour
announcements on this Mac (macOS keeps the LAN from it), so the tests type the address; a
real Apple TV asks for Local Network access and lists the homes.

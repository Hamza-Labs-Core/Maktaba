# `apps/` — native shells

Phase 11 scaffolds the platform wrappers that re-use the shared
`web/` SPA bundle.

| Subdir | Stack | Epic |
|---|---|---|
| [`apps/mobile/`](mobile/) | Capacitor 6 (iOS + Android) | Epic 12 |
| [`apps/desktop/`](desktop/) | Tauri 2 (macOS / Win / Linux) | Epic 13 |

Both wrappers expect `web/dist/` to exist; their build scripts call
`pnpm --filter maktaba-web build` to produce it before bundling.

The native projects (`apps/mobile/ios/`, `apps/mobile/android/`,
`apps/desktop/src-tauri/gen/`) are generated by the platform tooling
(`npx cap add`, `cargo tauri build`) and not checked in.

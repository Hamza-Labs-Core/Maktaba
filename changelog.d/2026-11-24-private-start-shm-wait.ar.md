### أُصلح

- **لم يعد انتقال قاعدة البيانات إلى PostgreSQL 18 يفشل في مكتبة أُوقفت قسرًا وشُغّلت فورًا.** يبدأ
  الانتقال بتشغيل قاعدة البيانات القديمة لاستعادتها. وبعد انقطاع الكهرباء أو الإيقاف القسري، كان هذا
  التشغيل قد يصادف ذاكرة ما زالت العمليات القديمة تمسكها («pre-existing shared memory block is still
  in use»): فيفشل الانتقال ويبقى المنزل على PostgreSQL 16 حتى تشغيله التالي. وهو ينتظر الآن حتى تتحرر
  الذاكرة. وكذلك كل تشغيل آخر يجريه البرنامج لقاعدة بياناته (استعادة نسخة، أو فحص مكتبة نُقلت)، وعلى
  Windows تشغيلها المعتاد أيضًا.

# المساهمة في مكتبة

مكتبة منصة وسائط تستضيفها بنفسك: تحوّل شجرة مجلدات من ملفات الفيديو إلى مكتبة قابلة للبث،
يمكن البحث فيها عن كل كلمة منطوقة، ولها تطبيقات رسمية للويب والهواتف والحواسيب وأجهزة التلفاز.
العربية لغة أساسية في كل جزء منها.

هذه الأدلة موجّهة إلى من يعملون على مكتبة نفسها: الخدمات والتطبيقات والاختبارات والتكامل
المستمر. الشيفرة المصدرية موجودة في
[github.com/Hamza-Labs-Core/Maktaba](https://github.com/Hamza-Labs-Core/Maktaba).

## الأدلة

- [نظرة عامة على البنية](architecture.ar.md): الخدمات وقاعدة البيانات وكيف تتواصل فيما
  بينها.
- [تنظيم المستودع](repo-layout.ar.md): المجلدات الرئيسية وما يحويه كل منها.
- [الإعداد المحلي](local-setup.ar.md): المتطلبات المسبقة وتشغيل بيئة تطوير.
- [تشغيل الاختبارات](tests.ar.md): كل مجموعة اختبارات، والمستويات، وبوابة الاختبارات المتأثرة.
- [الأعراف](conventions.ar.md): الإنجليزية والعربية معًا، والاختبارات مع الشيفرة، والأدوار
  المفروضة على الخادم، ولا أسرار في الشيفرة، وأسلوب الإيداعات.
- [أنواع المشكلات](problem-types.ar.md): أخطاء الواجهة البرمجية وسجلّها، وكيف تضيف نوعًا، والفحوص
  التي تُبقي الواجهة البرمجية والتطبيقات وmaktaba.tv متوافقة.
- [مستويات الواجهة البرمجية](api-levels.ar.md): كيف يعرف المنزل وتطبيقاته هل يستطيعون العمل معًا،
  والحد الأدنى للإصدارات، وأسماء منصات التلفاز، وكيف تغيّر استجابة بأمان.
- [الرقابة الأبوية](parental-controls.ar.md): لكاتبي التطبيقات والواجهة البرمجية: ما يجب على
  المشغّل فعله، والمسارات ورموزها، وسجل المسارات، وكيف تشغّل جدول الأدوار وتمرين الالتفاف.
- [التكامل المستمر](ci.ar.md): كيف يختار التكامل المستمر المهام التي يحتاجها كل تغيير، وبوابة الدمج الوحيدة.
- [طلبات الدمج](pull-requests.ar.md): أنشئ فرعًا، واختبر، واكتب الوصف، وراجع، وادمج.
- [سحابة مكتبة: كيف تبقى تعمل](cloud.ar.md): العقدتان، والنشر، والنسخ الاحتياطي، وتدريب السحابة.
- [مكتبة على خادم تخزين شبكي: كيف تتركّب الأجزاء](nas.ar.md): صورة واحدة لأي مستخدم، وما يكتشفه
  الخادم بنفسه، وملفات التثبيت، وأدلة maktaba.tv، والنصوص، والاختبارات.
- [مكتبة على جهاز تخزين شبكي: تطبيق TrueNAS](nas-apps.ar.md): تطبيق الكتالوج، واختباره بأدوات الكتالوج نفسها، وكيف تحرّكه الإصدارات.
- [موقع maktaba.tv: كيف يُبنى وكيف يُنشر](website.ar.md): البناء، والعامل، والنشر مع فحص المعاينة، والإطلاق، والتراجع.
- [قواعد الأمان للإضافات والمساهمين](../security/conformance.ar.md): ما يجب أن تلتزم به
  الإضافات والمساهمون، وكيف تبلّغ عن ثغرة.

## الخلاصة

```sh
git clone https://github.com/Hamza-Labs-Core/Maktaba.git
cd Maktaba
cp .env.example .env
make prereqs      # tells you which tools are missing
make dev          # live-reload stack
make test         # unit tier: no network, no sudo
```

يشغّل التكامل المستمر أهداف `make` نفسها التي تشغّلها محليًا، فإذا نجح `make lint` و`make test`
على جهازك فستنجح فحوص التدقيق واختبارات الوحدات كذلك.

## الإبلاغ عن مشكلة أمنية

لا تفتح بلاغًا عامًا عن ثغرة أبدًا. راسل security@maktaba.dev واطّلع على
[سياسة الإبلاغ](https://maktaba.dev/security/policy/).

## What we learned
- A reading-order test can run without pixel comparison: read each character's drawn position
  with a Range, sort by x, and compare with the NFKC fold of Roku's visual string (presentation
  forms fold back to the letters).
- `document.fonts.check` is the wrong tool for "is the Arabic font in use". It returns true when
  the family has no face at all, and false when a duplicate face is still unloaded (the receiver
  declares its faces twice). Instead, check that a loaded face of the element's family covers
  each Arabic letter.
- The receiver's Playwright webServer port (8791) can be held by another session's wrangler.
  Start a wrangler on another port and set `CAST_BASE`.

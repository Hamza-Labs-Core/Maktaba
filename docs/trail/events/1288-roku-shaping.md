## What we learned
- Roku draws a Label's characters left to right with no joining and no bidi: Arabic must
  arrive shaped and in display order, and every screen mirrored by hand.
- python-bidi leaves L4 mirroring to the renderer; Roku's renderer does not do it, so the
  reference applies it.
- brs-node needs Node 22+ (iterator helpers): the Roku job reads `apps/tv/roku/.nvmrc` (24),
  not web's (20).
- The link check reads every file, so sample addresses in test data must be example.org.
- brs-engine costs about 0.6 µs a statement and 10 µs a call: the hot loops make no
  per-character calls.

## Keep doing
- Generate device tables from a reference implementation so data and reference cannot drift.
- Ship the groundwork story first, with its vectors, so the screens that use it test against it.

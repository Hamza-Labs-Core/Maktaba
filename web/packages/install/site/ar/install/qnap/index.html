تثبيت Maktaba على خادم QNAP

يشغّل تطبيق «Container Station» برنامج Maktaba من ملف compose واحد.

كل أدلة خوادم التخزين · English

لم تُجرَّب هذه الخطوات بعد على جهاز QNAP. وهي تتبع خطوات QNAP نفسها، والملف نفسه يعمل على كل جهاز فيه Docker. أخبرنا بما تجده على GitHub.

لنظام QTS ‏5.1 أو QuTS hero ‏5.1 وما بعدهما، مع تطبيق «Container Station 3» من مركز التطبيقات. يستغرق التثبيت نحو 20 دقيقة.

قبل أن تبدأ

  • الذاكرة: ‏8 غيغابايت أو أكثر مريحة، ويعمل Maktaba بدءًا من 4 غيغابايت.
  • تحويل الفيديو بالعتاد: الطرازات التي فيها معالج Intel من فئة Celeron أو Pentium ‏(TS-464 وTS-264 وTS-462 وغيرها) تحوّل الفيديو بتقنية Quick Sync عبر /dev/dri.
  • المنفذ 8080: يحجزه نظام QTS لصفحاته. يلاحظ Maktaba ذلك وينقل منفذه إلى ما بين 8780 و8790، ويعرض الإعداد وصفحة «الإعدادات ← هذا الجهاز» المنفذ الجديد. لا تحتاج إلى فعل شيء.

1. أنشئ مستخدمًا لـ Maktaba

من «Control Panel» ← «Privilege» ← «Users» ← «Create» ← «Create a User»: سمّه maktaba، بكلمة مرور قوية، ودون صلاحيات المدير. ثم اقرأ رقميه: فعّل SSH (من «Control Panel» ← «Network & File Services» ← «Telnet / SSH») وشغّل الأمر id maktaba. فالنتيجة uid=1001 gid=100 تعني الإجابة 1001:100.

2. امنحه مجلداته

  • البيانات: أنشئ المجلد maktaba داخل المجلد المشترك Container (ينشئه «Container Station»، واجعله على قرص SSD إن وُجد)، وامنح maktaba صلاحية القراءة والكتابة عليه.
  • الوسائط: من «Control Panel» ← «Privilege» ← «Shared Folders» ← كل مجلد فيه مقاطع ← «Edit Shared Folder Permission»: القراءة والكتابة لـ maktaba حيث يحفظ Maktaba الترجمات والتحويلات، والقراءة فقط في غيرها.

ومسار المجلد المشترك داخل الحاوية هو مساره على الخادم نفسه، مثل /share/Multimedia أو /share/CACHEDEV1_DATA/Movies.

3. أنشئ ملف compose

افتح صفحة التثبيت، واختر QNAP، وأجب: المستخدم (1001:100)، والذاكرة، ومجلد البيانات (/share/Container/maktaba)، ومجلدات وسائطك، وتحويل الفيديو بالعتاد، والمنطقة الزمنية. ثم انسخ الملف. لا يغادر شيء مما تكتبه هناك الصفحة.

4. أنشئ التطبيق

من «Container Station» ← «Applications» ← «Create»: سمّه maktaba، والصق الملف، ثم «Create». فينزّل «Container Station» الصورة ويشغّلها.

5. شغّل الإعداد

شغّل عبر SSH:

docker exec -it maktaba /opt/maktaba/server/bin/maktaba-server container setup

أجب عن أسئلته: اسمٌ لحساب المدير (غير admin الذي يحتفظ به Maktaba لنفسه)، وكلمة مروره، والمجلدات التي فيها مقاطعك. ويحتاج الخادم إلى الإنترنت في هذه الخطوة: ينزّل الإعداد أدوات التفريغ والبحث (نحو 2 GB) ونماذج الكلام. ويبدأ Maktaba بنفسه حين ينتهي. ثم افتح http://<your NAS>:8088. وسجّل الدخول بعدها، وأضف مكتبة لكل مجلد: «الإدارة ← إدارة المكتبات ← إضافة مكتبة» (بعد الإعداد).

بعد الإعداد

بعد الإعداد: الأذونات، وساعات الهدوء، وتحويل الكلام إلى نص، وتحويل الفيديو بالعتاد، والوكيل العكسي، والتحديثات، وإضافة حاسوب فيه معالج رسوميات. حل المشكلات: معنى كل رسالة.

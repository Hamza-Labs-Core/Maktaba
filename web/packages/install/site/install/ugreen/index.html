Install Maktaba on UGREEN or ASUSTOR

Both run Maktaba from one compose file.

All NAS guides · العربية

For UGOS Pro (the DXP models) with the Docker app, and ADM 4.2 and newer with Portainer from App Central. About 20 minutes.

Before you start

  • Memory: 8 GB or more is comfortable; Maktaba runs from 4 GB.
  • Hardware video: the Intel models (N100, Pentium, Core, Celeron) convert video with Quick Sync through /dev/dri.
  • An SSD for the data folder if there is one: the database and thumbnails are much faster there.

1. Make a user and read its numbers

UGREEN: Control Panel → User → Create: name maktaba, not an administrator. ASUSTOR: Access Control → Local Users → Add. Then, over SSH (turn it on in the NAS's terminal settings), run id maktaba: uid=1001 gid=100 is the answer 1001:100.

2. Give it its folders

Make a folder for Maktaba's data, such as /volume1/docker/maktaba on UGREEN or /volume1/Docker/maktaba on ASUSTOR, and give maktaba Read/Write on it. For each shared folder with videos, give maktaba Read/Write where Maktaba may save subtitles and conversions, Read only elsewhere.

3. Make the compose file

Open the install page, choose UGREEN or ASUSTOR, and answer: the user, the memory, the data folder, your media folders, hardware video and the time zone. Copy the file. Nothing you type there leaves the page.

4. Create the project

  • UGREEN: Docker → Project → Create: name maktaba, its folder under /volume1/docker, paste the file, Deploy.
  • ASUSTOR: install Portainer CE from App Central, then Stacks → Add stack: name maktaba, paste the file, Deploy the stack.

5. Run the setup

Over SSH, run:

sudo docker exec -it maktaba /opt/maktaba/server/bin/maktaba-server container setup

Answer its questions: a name for the admin account (not admin, which Maktaba keeps for itself), its password, and the folders with your videos. The NAS needs the internet for this step: setup downloads the transcription and search tools (about 2 GB) and the speech models. Maktaba starts by itself when it finishes. Open http://<your NAS>:8088. Sign in, then add a library for each folder: Manage → Manage libraries → Add library (After setup).

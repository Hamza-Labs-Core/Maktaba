Install Maktaba on a QNAP NAS

Container Station runs Maktaba from one compose file.

All NAS guides · العربية

Not yet tested on a QNAP device. The steps follow QNAP's own and the same file runs on every Docker host; tell us at GitHub what you find.

For QTS 5.1 or QuTS hero 5.1 and newer, with Container Station 3 from App Center. About 20 minutes.

Before you start

  • Memory: 8 GB or more is comfortable; Maktaba runs from 4 GB.
  • Hardware video: models with an Intel Celeron or Pentium (TS-464, TS-264, TS-462 and others) convert video with Quick Sync through /dev/dri.
  • Port 8080: QTS keeps it for its own pages. Maktaba sees that, moves its own port into 8780 to 8790, and setup and Settings → This machine show the new one. You do nothing.

1. Make a user for Maktaba

Control Panel → Privilege → Users → Create → Create a User: name maktaba, a strong password, not an administrator. Then read its numbers: over SSH (Control Panel → Network & File Services → Telnet / SSH), run id maktaba. uid=1001 gid=100 is the answer 1001:100.

2. Give it its folders

  • Data: create the folder maktaba inside the shared folder Container (Container Station makes it; put it on an SSD volume when there is one), and give maktaba Read/Write on it.
  • Media: Control Panel → Privilege → Shared Folders → each folder with videos → Edit Shared Folder Permission: Read/Write for maktaba where Maktaba may save subtitles and conversions, Read only elsewhere.

A shared folder's path in the container is its path on the NAS, such as /share/Multimedia or /share/CACHEDEV1_DATA/Movies.

3. Make the compose file

Open the install page, choose QNAP, and answer: the user (1001:100), the memory, the data folder (/share/Container/maktaba), your media folders, hardware video and the time zone. Copy the file. Nothing you type there leaves the page.

4. Create the application

Container Station → Applications → Create: name maktaba, paste the file, Create. Container Station downloads the image and starts it.

5. Run the setup

Over SSH, run:

docker exec -it maktaba /opt/maktaba/server/bin/maktaba-server container setup

Answer its questions: a name for the admin account (not admin, which Maktaba keeps for itself), its password, and the folders with your videos. The NAS needs the internet for this step: setup downloads the transcription and search tools (about 2 GB) and the speech models. Maktaba starts by itself when it finishes. Open http://<your NAS>:8088. Sign in, then add a library for each folder: Manage → Manage libraries → Add library (After setup).

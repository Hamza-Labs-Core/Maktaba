Install Maktaba

Choose the computer that will run Maktaba. Each guide takes you through it step by step, in your browser, and Maktaba updates itself afterwards.

On a NAS

Not sure which guide fits your NAS? Find your NAS: the list of models says which guide to follow.

  • Synology: DSM 7.2 or newer, with Container Manager.
  • TrueNAS: TrueNAS 25.04 or newer, as a custom app.
  • Unraid: from Community Applications.
  • QNAP: with Container Station.
  • UGREEN or ASUSTOR: with their Docker app.

On any other computer

Install with Docker on any Linux computer that stays on: the guide fills in the compose file for you as you answer.

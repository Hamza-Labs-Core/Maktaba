# Phase 2 review: the built pages beside part B's mockups (DRAFT)

**Status: draft, written with the pull request that built the home page (story 60.10). The lead
completes and signs it (the table at the end). The download page (60.11) and the help pages
(60.12) add their own sections when they ship.**

Each page is compared at 360, 768 and 1280 px, in English and Arabic, dark, and light at 1280 px:
the built page's visual reference (`e2e/__screenshots__/`, rendered on Linux in the CI image)
beside its part B mockup (`mockups/png/`). The tests' browser (Playwright's "Desktop Chrome") sends a Windows user agent, so the references show
the Download button as a Windows visitor sees it ("Download for Windows"); a Mac visitor's reads
"Download for Mac", as the mockup draws it, and a system without a label of its own "Download
Maktaba". The references mask the screenshots in the frame's near-black (`SHOT_MASK` in
`e2e/visual.spec.ts`): they hold the frames, their sizes and the captions; the pictures
themselves are compared with the mockups in the built page (`npm run build`, then `npm run dev`).

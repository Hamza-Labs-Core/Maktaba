Recommended defaults

For most home Windows machines we recommend installing to C:\Program Files\Maktaba, enabling the Maktaba service, and choosing a media library folder on your largest drive.

Custom drive? If your videos are on a separate drive (e.g. D:\Media), point the library folder there during install — Maktaba won't move files, just index them in place.
NTFS only Maktaba requires NTFS (not FAT32 or exFAT) for the install location and the cache directory. Library folders on other filesystems work fine.

Step 3 · Service & Windows Firewall

Two automated dialogs · approve both to enable streaming

Service: "Maktaba Server"

The installer creates a Windows service named MaktabaServer set to start automatically. It runs as NT SERVICE\MaktabaServer with limited privileges — it can read your library, but cannot touch system files.

Firewall: allow on private networks

Windows Firewall asks whether Maktaba can communicate. Tick Private networks (home Wi-Fi). Leave Public networks unticked unless you specifically need it.

Windows Defender Firewall

Windows Defender Firewall has blocked some features of Maktaba Server on all public, private and domain networks.

Setup wizard launches in your default browser

After install completes, Maktaba opens http://localhost:8000/setup. Pick your library folder, choose a transcription engine (CUDA accelerated if you have an NVIDIA GPU), link Cloud, and run the initial scan.

The wizard runs locally · no data leaves your PC unless you opt into Cloud.

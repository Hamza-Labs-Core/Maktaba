Run Maktaba in Docker

Self-host on Linux, macOS, Windows, or any Docker-compatible OS. Uses ~600 MB RAM idle, supports CUDA & ROCm GPU passthrough, and runs as an unprivileged user.

image:ghcr.io/maktaba/server tag:v1.0.0 size:218 MB arch:linux/amd64, linux/arm64 latest pull:14k this week

Step 1 · Save this docker-compose.yml

Pre-configured with sensible defaults · edit volume paths to match your setup

docker-compose.yml 
# Maktaba media server · docker-compose.yml
# Quickstart: docker compose up -d

services:
  maktaba:
    image: ghcr.io/maktaba/server:v1.0.0
    container_name: maktaba
    restart: unless-stopped
    user: "1000:1000"           # run as your UID:GID

    ports:
      - "8000:8000"             # web UI & HTTP API
      - "8443:8443"             # HTTPS (optional)

    volumes:
      - ./config:/config         # settings, db, secrets
      - ./cache:/cache           # transcoded segments, thumbnails
      - /path/to/media:/media:ro # your library (read-only)

    environment:
      MAKTABA_PUBLIC_URL: "http://maktaba.local:8000"
      MAKTABA_TZ: "America/New_York"
      MAKTABA_TRANSCRIPTION_ENGINE: "whisper-cpu"
      MAKTABA_LOG_LEVEL: "info"
      # MAKTABA_CLOUD_TOKEN: "tok_..."  # paste from cloud.maktaba.app

    healthcheck:
      test: ["CMD", "curl", "-f", "http://localhost:8000/health"]
      interval: 30s
      timeout: 5s
      retries: 3
      start_period: 40s

    # GPU acceleration (uncomment for NVIDIA hosts):
    # deploy:
    #   resources:
    #     reservations:
    #       devices:
    #         - driver: nvidia
    #           count: 1
    #           capabilities: [gpu]

Step 3 · Configure volume mounts

Three mounts: persistent config, transient cache, your media library

PERSISTENT

./config → /config

/srv/maktaba/config → /config
SQLite database, secrets, settings JSON, server identity certificate. Back this up. Survives image upgrades.
TRANSIENT

./cache → /cache

/srv/maktaba/cache → /cache
Transcoded HLS segments, thumbnails, ML model checkpoints. Safe to delete — Maktaba regenerates.
READ-ONLY · MEDIA

/path/to/videos → /media

/mnt/library → /media:ro
Your existing video library. Mount read-only — Maktaba never modifies your originals. Multiple /media-N mounts supported.
OPTIONAL · MODELS

./models → /models

/srv/maktaba/models → /models
Pre-downloaded Whisper checkpoints. Skip to let Maktaba download on first scan (~1.5 GB for medium).

Common operations

Update, view logs, back up, stop · everything else is in docker compose

Update to latest
docker compose pull
docker compose up -d
# pulls new image, recreates container,
# keeps your config + cache
Tail logs
docker compose logs -f maktaba
# Ctrl+C to stop tailing

docker compose logs --since 1h \
  | grep ERROR
Backup config
docker compose stop
tar czf maktaba-backup-$(date +%F).tar.gz \
  config/
docker compose start
Stop & remove
# stop, keep volumes
docker compose down

# nuke everything, including data
docker compose down -v
rm -rf config cache

All UI states · Docker install

Common errors, GPU detection, healthcheck failures
Port already in use CONFLICT
Port 8000 already in use Another service is bound to :8000. Change to "8080:8000" in compose, or stop the conflicting service.
Permission denied on volume PERMS
EACCES /config: permission denied Container UID 1000 cannot write to ./config. Run "sudo chown -R 1000:1000 config cache" or set PUID/PGID to your user.
GPU detected CUDA
NVIDIA GPU detected · driver 545.23 nvidia-container-toolkit is installed. Uncomment the deploy.resources block in compose to use GPU acceleration.
Healthcheck failing HEALTH
Healthcheck failing 3/3 Container is up but /health returns 500. Check logs: "docker compose logs maktaba | tail -50". Common cause: corrupt SQLite db.
Image pull rate-limited RATE LIMIT
Pull throttled · Docker Hub anonymous limit You've hit 100 pulls/6h. Switch to ghcr.io (image is mirrored there with no rate limit) or sign in: "docker login".
Wrong arch warning ARCH
Image arch is amd64 — host is arm64 Maktaba supports linux/arm64 natively. Add "platform: linux/arm64" to compose, or it'll run via emulation (~3× slower).
Compose v1 deprecated DEPRECATED
"docker-compose" is v1 (deprecated) Switch to v2 — built into Docker as "docker compose" (no hyphen). Maktaba's compose file uses v2 syntax (no top-level version).
Toast · code copied CLIPBOARD
docker-compose.yml copied Paste into a file and run "docker compose up -d"
×
Network unreachable NETWORK
ghcr.io not reachable DNS or firewall blocking. Test: "curl -I https://ghcr.io". If behind a proxy, set HTTP_PROXY/HTTPS_PROXY in your Docker daemon.

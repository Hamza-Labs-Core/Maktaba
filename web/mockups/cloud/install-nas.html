Step 2 · Confirm install & review permissions

Synology lists what the package will access · Maktaba uses minimal permissions

Install Maktaba Server

The package wants the following permissions on your DiskStation:

File access read-only on /volume1/video and selected shared folders
Network listen on TCP 8000 · outbound HTTPS for Cloud relay
System create user "maktaba" with limited shell · no root
Storage 14 GB on the volume of your choice (config + cache + models)
Login auto-start on DSM boot · run as user "maktaba"

Signed by Maktaba Studio LLC · verified by Synology Package Trust

Read-only mounts by default

Maktaba reads videos from your existing shared folders (e.g. /volume1/video) but never modifies them. Config and transcoded segments live in the Maktaba app data folder, isolated from your media.

The package creates a system user named maktaba with no shell login and no sudo access — strictly less privilege than admin.

Use Synology's reverse proxy for HTTPS

Maktaba ships HTTP-only by default. To get HTTPS at https://maktaba.your-nas.synology.me, use Control Panel → Login Portal → Reverse Proxy. We have a 5-step guide with screenshots.

CPU-only transcription Most Synology models lack a discrete GPU. Maktaba auto-selects whisper-cpu small on NAS hardware — fast enough for ~3 minutes of video per minute of CPU on a DS920+.

Step 4 · Open Maktaba from the DSM main menu

The Maktaba icon appears in your DSM main menu & on the desktop

Click the Maktaba icon · setup wizard launches

The package adds an icon to your DSM main menu and (optionally) your desktop. Click it to open the web UI in a new tab — the setup wizard auto-launches on first run.

You can also reach Maktaba directly at http://your-nas:8000.

QPKG installation

QNAP installs are nearly identical to Synology — search, click Install, agree to permissions. The package creates a non-privileged user, listens on TCP 8000, and registers an app icon on your QTS desktop.

Sideload from .qpkg App Center → Install Manually → upload maktaba-server-1.0.0.qpkg. Useful when QNAP hasn't approved the latest version yet.

Permission gotchas, hardware compatibility, and platform-specific dialogs
DSM version too old UNSUPPORTED
DSM 6.2 is not supported Maktaba requires DSM 7.0+. Update via Control Panel → Update & Restore. DSM 7 is free for all supported models.
CPU not supported · ARM CPU
Realtek RTD1296 (DS118) detected Transcription will be slow — about 8× realtime. Consider a Celeron/x86 NAS or use a Mac/PC for the server, with the NAS as remote storage.
Port already in use PORT
Port 8000 in use by Jellyfin Choose another port — recommended 8800 or 9000. We'll update the package config and restart automatically.
Insufficient RAM warning RAM
2 GB RAM may be tight DS220j has 512 MB. Maktaba runs but transcription is constrained — limit to 1 concurrent transcribe job in settings.
Folder permission needed PERMS
Grant access to /volume1/video

Maktaba needs read-only access to the shared folder /volume1/video to scan your library. It will not create or modify files.

Granting will add user "maktaba" to the share's read-only ACL.
